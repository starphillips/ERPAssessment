# ERP Assessment

A small ASP.NET Core Web API project used as the starting point for a .NET assessment.

## Run

```bash
dotnet restore
dotnet run
```

Open Swagger from the URL shown in the console, usually:

`https://localhost:<port>/swagger`

## Existing API

- `GET /api/employees`
- `GET /api/employees/{id}`
- `POST /api/employees`

The candidate should extend this same application during the assessment.
